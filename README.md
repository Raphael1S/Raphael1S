# Olá, eu sou o Raphael 👋

Sou estudante e desenvolvedor apaixonado por tecnologia, com foco em desenvolvimento backend, automação e criação de plugins para servidores Minecraft.  
Tenho experiência com PHP, PHAR, Python, Lua e integração de sistemas, sempre buscando criar soluções eficientes, organizadas e escaláveis.

---

## 🚀 Projetos em Destaque

### 🔹 [MathEvent](https://github.com/Raphael1S/Math-Event)
Plugin para PocketMine-MP que adiciona eventos matemáticos automáticos e interativos dentro do servidor.

### 🔹 [Prison-System](https://github.com/Raphael1S/Prison-System)
Sistema de prisão para PocketMine-MP, permitindo gerenciamento de punições e controle de jogadores.

### 🔹 [AutoClicker](https://github.com/Raphael1S/AutoClicker)
Plugin que automatiza ataques em mobs dentro do PocketMine-MP.

### 🔹 [Tp-All](https://github.com/Raphael1S/Tp-all)
Plugin simples e eficiente para teletransportar todos os jogadores até o administrador.

### 🔹 [Fix-Localization](https://github.com/Raphael1S/Fix-Localization)
Correção para o problema de localização infinita em servidores PocketMine-MP.
